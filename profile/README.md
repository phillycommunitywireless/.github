# Welcome to Philly Community Wireless on Github!

Philly Community Wireless is building community-controlled wireless internet networks in Philadelphia. We aim to provide a baseline of internet access for everyone, enhancing quality of life today and positioning communities for a more healthy and prosperous tomorrow. We are committed to expanding internet access, growing tech literacy, and building community autonomy with our neighbors. Through our unique community internet model, we partner with local organizations and neighbors to expand digital access where it's needed most.

To learn more about our staff, boards, and other people involved in our work, visit [our website](https://phillycommunitywireless.org/about/people/). For updates about our work, sign up for our newsletter and follow us on social media @phillycommunitywireless.

## How our sites are built and deployed

| Site | Production | Pull request previews |
|---|---|---|
| [phillycommunitywireless.org](https://phillycommunitywireless.org) | Hugo → GitHub Pages | Render |
| [docs.phillycommunitywireless.org](https://docs.phillycommunitywireless.org) | mkdocs → Read the Docs | Render |
| [map.phillycommunitywireless.org](https://map.phillycommunitywireless.org) | Jekyll → GitHub Pages | Render |

Every pull request against these repositories gets a live preview URL, so you can review a change without building anything locally. Details are on the [wiki](https://github.com/phillycommunitywireless/phillycommunitywireless/wiki).

## Licensing

Our repositories are **MIT licensed** unless noted otherwise. Public code without a license file cannot legally be reused, which defeats the point of publishing a model meant to be replicated — so every repository we intend others to build on carries one.
